# 344. Reverse String

**LeetCode:** [344. Reverse String](https://leetcode.com/problems/reverse-string/) · **Difficulty:** Easy
<!-- meta:end -->

<!-- doc-status: written -->
## Problem

Reverse a list of characters **in place**, using only O(1) extra memory.

## Input

- `s`: list of single-character strings (modified in place)

## Output

- Nothing is returned; `s` ends up reversed.

## Constraints

- 1 ≤ `len(s)` ≤ 10⁵
- Printable ASCII characters

## Edge cases

- Single character
- Even and odd lengths
- Palindromes

## Examples

| Input | Output | Why |
|---|---|---|
| `["c", "a", "t"]` | `["t", "a", "c"]` | reversed |
| `["z"]` | `["z"]` | single character |
