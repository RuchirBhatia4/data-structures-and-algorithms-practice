# 206. Reverse Linked List

**LeetCode:** [206. Reverse Linked List](https://leetcode.com/problems/reverse-linked-list/) · **Difficulty:** Easy
<!-- meta:end -->

<!-- doc-status: written -->
## Problem

Reverse a singly linked list and return the new head.

## Input

- `head`: first node of a singly linked list (or `None`)

## Output

- The head of the reversed list.

## Constraints

- 0 to 5000 nodes
- −5000 ≤ `Node.val` ≤ 5000
- Follow-up: write both an iterative and a recursive version

## Edge cases

- Empty list
- Single node
- Two nodes

## Examples

| Input | Output | Why |
|---|---|---|
| `1 → 2 → 3` | `3 → 2 → 1` | links point the other way |
| `empty list` | `empty list` | nothing to reverse |
| `9` | `9` | single node |
