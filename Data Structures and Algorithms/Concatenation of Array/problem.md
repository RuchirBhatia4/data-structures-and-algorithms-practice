# 1929. Concatenation of Array

**LeetCode:** [1929. Concatenation of Array](https://leetcode.com/problems/concatenation-of-array/) · **Difficulty:** Easy
<!-- meta:end -->

<!-- doc-status: written -->
## Problem

Build a list twice as long as the input: the input followed by another copy of the input.

## Input

- `nums`: list of integers

## Output

- A list of length `2n` equal to `nums` followed by `nums`.

## Constraints

- 1 ≤ `len(nums)` ≤ 1000
- 1 ≤ `nums[i]` ≤ 1000

## Edge cases

- Single element
- Repeated values

## Examples

| Input | Output | Why |
|---|---|---|
| `[7, 2]` | `[7, 2, 7, 2]` | copy appended |
| `[5]` | `[5, 5]` | single element |
