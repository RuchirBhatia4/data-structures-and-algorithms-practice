# 9. Palindrome Number

**LeetCode:** [9. Palindrome Number](https://leetcode.com/problems/palindrome-number/) · **Difficulty:** Easy
<!-- meta:end -->

<!-- doc-status: written -->
## Problem

Decide whether an integer reads the same forwards and backwards in base 10.

## Input

- `x`: integer

## Output

- `True` if `x` is a palindrome, otherwise `False`.

## Constraints

- −2³¹ ≤ `x` ≤ 2³¹ − 1
- Follow-up: solve it without converting to a string

## Edge cases

- Negative numbers (the minus sign breaks symmetry)
- Trailing zeros
- 0
- Single digit

## Examples

| Input | Output | Why |
|---|---|---|
| `12321` | `True` | symmetric |
| `-7` | `False` | reads "7-" backwards |
| `120` | `False` | reads "021" |
| `0` | `True` | single digit |
