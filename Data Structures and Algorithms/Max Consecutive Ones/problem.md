# 485. Max Consecutive Ones

**LeetCode:** [485. Max Consecutive Ones](https://leetcode.com/problems/max-consecutive-ones/) · **Difficulty:** Easy
<!-- meta:end -->

<!-- doc-status: written -->
## Problem

In a list made only of 0s and 1s, find the length of the longest unbroken run of 1s.

## Input

- `nums`: list of 0s and 1s

## Output

- The length of the longest run of consecutive 1s.

## Constraints

- 1 ≤ `len(nums)` ≤ 10⁵
- Each value is 0 or 1

## Edge cases

- No 1s at all
- All 1s
- Longest run at the very end

## Examples

| Input | Output | Why |
|---|---|---|
| `[1, 0, 1, 1, 0, 1]` | `2` | the run in the middle |
| `[0, 0]` | `0` | no ones |
| `[1, 1, 1]` | `3` | whole list |
