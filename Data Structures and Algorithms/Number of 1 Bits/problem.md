# 191. Number of 1 Bits

**LeetCode:** [191. Number of 1 Bits](https://leetcode.com/problems/number-of-1-bits/) · **Difficulty:** Easy
<!-- meta:end -->

<!-- doc-status: written -->
## Problem

Count how many bits are set to 1 in the binary representation of a positive integer.

## Input

- `n`: positive integer

## Output

- The number of 1 bits.

## Constraints

- 1 ≤ `n` ≤ 2³¹ − 1
- Follow-up: how would you optimize if this is called many times?

## Edge cases

- Powers of two (one set bit)
- All bits set
- 1

## Examples

| Input | Output | Why |
|---|---|---|
| `13` | `3` | binary 1101 |
| `1` | `1` | binary 1 |
| `255` | `8` | binary 11111111 |
