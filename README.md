# Data Structures and Algorithms Practice

My Python solutions to data structures and algorithms problems, one folder per problem.

Each folder contains:

- `problem.md`: the problem in my own words, with a link to the official LeetCode problem
- `my_solution.py`: my solution (later versions are in `attempts/`)
- `handwritten_approach.*`: my handwritten approach, where I made one
- `optimal_solution.py`: my optimized solution, where I wrote one
